# A股高股息低风险长线策略设计（草案）

## 1. 策略目标

- 市场范围：A股主板 + 红利风格常见板块，剔除高波动板块。
- 持仓周期：3年起步，目标10年。
- 收益底线：初始年收益不低于3%。
- 长期目标：年化总收益10%（含分红再投资）。
- 风险约束：组合历史最大回撤不超过5%。

## 2. 核心选股要求

- 低PE：行业内估值中低分位。
- 高稳定：近3年年化波动率处于行业低分位，且ROE波动较小。
- 高年度分红：近3年平均股息率不低于3%，分红连续性达标。
- 跨周期行业：优先消费、公用事业、能源、交通、通信等盈利韧性较强行业。
- 行业前五：仅保留各行业按市值排名前五的公司。

## 3. 策略框架

### 3.1 四层结构

1. 基础过滤层：剔除ST、退市风险、流动性不足标的。
2. 股息质量层：股息率门槛、分红连续性、股息率波动约束。
3. 稳定性层：波动率与ROE稳定性双过滤。
4. 估值与排序层：低PE优先，结合质量因子形成综合评分。

### 3.2 调仓与持有

- 月度：更新股票池（只影响新开仓候选）。
- 季度：执行再平衡（降低换手，贴合长线）。
- 日度：执行风控巡检（个股止损、止盈、极端风险事件）。

### 3.3 选股与回测的分层架构

当前实现采用“选股前置 + 策略执行”的轻量架构：

- 选股阶段：在 `build_monthly_high_dividend_universe()` 中按月生成候选股票池。
- 回测阶段：在 `HighDividendLowRiskLongTermStrategy` 中仅依据当月可用候选池执行新开仓、止损和止盈。
- 运行入口：在 `main()` 中先构建月度股票池，再进入回测。

这是一个低耦合设计：不修改现有策略模块，不新增复杂结构；只在独立策略文件中完成长线候选池与执行逻辑。

### 3.4 严格模式与宽松模式

当前实现保留两层筛选逻辑：

1. 严格模式（优先）：
   - 目标是筛选高股息、低波动、低ROE波动、低PE分位的高质量候选。
   - 适用于追求更稳定的长期配置。
   - 但如果在某些月份没有足够候选，会出现空池。

2. 宽松模式（兜底）：
   - 当严格模式无有效标的时自动回退。
   - 降低股息门槛、扩展PE和波动限制。
   - 目标是避免长期空仓，保留策略执行能力。

这两种模式的关系不是互斥，而是：优先严格筛选，失败时自动退回宽松模式，确保策略可以继续运转。

### 3.5 回撤 5% 的定位

回撤 5% 作为长期目标，不作为股票池筛选条件。

- 它不是：`max_drawdown_limit` 这类硬过滤参数。
- 它是：回测结果评估目标，用来判断策略是否满足低风险要求。

因此，当前代码将 5% 放在“绩效目标”而不是“选股门槛”中，以避免一味压缩候选池，导致策略风控过强却丧失操作性。

## 4. 参数建议（首版）

| 参数 | 建议值 | 说明 |
|---|---:|---|
| `min_dividend_yield_3y_avg` | 3.0% | 近3年平均股息率下限 |
| `max_industry_rank` | 5 | 行业市值排名上限 |
| `pe_quantile_max` | 0.7 | 行业内PE分位上限（越低越便宜） |
| `vol_quantile_max` | 0.5 | 行业内3年波动率分位上限 |
| `roe_vol_quantile_max` | 0.5 | 行业内ROE波动分位上限 |
| `max_positions` | 8-12 | 持仓数量区间 |
| `single_position_cap` | 8%-10% | 单标的权重上限 |
| `industry_cap` | 20%-30% | 单行业权重上限 |
| `cash_buffer` | 10%-20% | 现金缓冲区间 |
| `max_drawdown_target` | 5% | 组合历史最大回撤目标，不作为筛选条件 |

说明：当前版本已将 5% 从筛选门槛移出，保留为绩效目标，避免在选股阶段直接把候选池压空。

## 5. 风控优先级

1. 组合级回撤闸门：触发回撤阈值后，优先减仓并暂停新增仓位。
2. 事件级退出：ST、重大财务恶化、流动性显著下降。
3. 个股保护：极端单日波动或连续异常波动触发保护性降仓。

## 6. 收益与复利测算设计

### 6.1 目标检验

- 年度底线：每年收益率 >= 3%。
- 长期目标：年化总收益率 >= 10%。
- 风险目标：历史最大回撤 <= 5%。

### 6.2 复利拐点分析

- 统计累计净值达到 1.5x、2.0x、3.0x 的时间点。
- 识别收益加速区间，评估长期持有价值。
- 对比“分红再投资”和“不再投资”两种路径的长期差异。

## 7. 回测与验证计划

1. 回测周期：至少10年，覆盖牛市、熊市、震荡市。
2. 关键指标：年化收益、波动率、最大回撤、Sortino、Calmar、VaR/CVaR。
3. 稳健性验证：小范围参数敏感性测试（股息阈值、持仓数、行业上限）。
4. 现实约束：加入交易成本、滑点、停牌与涨跌停约束。

### 7.1 已验证的首次运行结果

已按当前实现完成一次真实回测，验证信息如下：

- 总收益率：47.30%
- 年化收益：8.58%
- 最大回撤：18.37%
- Sharpe：0.995
- Sortino：1.501
- 报告输出：reports/high_dividend_low_risk_20260921_214450.html

结论：当前版本可运行，且策略执行逻辑已跑通；但最大回撤仍远高于 5% 目标，因此 5% 仍属于长期目标，暂未作为筛选条件落地。

### 7.2 选股结果产出方式

当前代码会生成月度候选池，并保存到缓存目录：

- selector_data/monthly_high_dividend_universe_cache/

输出文件为 CSV，每个月一个文件，保存格式为：

- `symbol`
- `industry`
- `market_cap`
- `dividend_yield_3y_avg`
- `score`

这类 CSV 主要用于：

- 复用选股结果
- 避免重复重新构建股票池
- 将选股与回测解耦，确保策略只控制执行逻辑

### 7.3 运行方式说明

当前策略可直接运行：

- 先设置环境变量 `TUSHARE_TOKEN`
- 运行脚本：`python akq_stock_strategy_high_dividend_low_risk.py`

脚本在 `main()` 中会自动：

1. 构建月度股票池
2. 在严格模式失败时回退到宽松模式
3. 加载行情数据
4. 进入策略执行
5. 报告回测结果

### 7.4 当前版本状态

已确认：

- 选股和回测逻辑分层明确
- 严格/宽松模式可切换
- 不依赖新增数据目录
- 不修改现有核心模块行为
- 当前版本是可运行的独立 MVP

后续如果要继续推进低风险目标，需要在不破坏现有架构的前提下，进一步调优：

- 个股止损阈值
- 止盈触发阈值
- 季度建仓频率
- 候选池的收益/风险平衡

而不是直接将 5% 挖到筛选条件里。

## 8. 预期难点与处理

- 难点1：回撤<=5%与年化10%可能冲突。
  - 处理：优先满足回撤约束，必要时提高现金缓冲并降低权益暴露。
- 难点2：股息高但成长不足。
  - 处理：在排序中加入盈利质量与成长稳定因子，避免单一高股息陷阱。
- 难点3：行业集中风险。
  - 处理：严格行业权重上限与候选替补机制。

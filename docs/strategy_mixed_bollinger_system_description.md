# 基本面 + 布林/ADX 共振策略系统说明

## 1. 系统目标
该策略系统用于 A 股多标的组合回测，核心目标是把选股、择时、仓位控制和风险退出整合到一个统一流程中。

系统由四层组成：
1. 选股层：基于基本面与流动性过滤，生成可交易股票池。
2. 信号层：基于布林线和 ADX 共振触发买入，布林触发常规卖出。
3. 组合层：执行固定仓位、总持仓上限和行业上限约束。
4. 风控层：执行强制止损和动态止盈，优先级高于常规卖出。

## 3. 选股层设计

### 3.1 行业覆盖
采用五行业配置，并支持电池关键词补充纳入。

五行业分组：
1. 医疗/医药
2. 半导体
3. 电池(锂电)
4. 有色金属
5. 化工

行业过滤逻辑：
1. 股票所属行业在目标行业集合内则纳入。
2. 股票名称命中电池关键词也可纳入。

### 3.2 过滤规则
当前选股规则共 10 条：
1. 行业筛选（五行业 + 电池关键词）
2. 毛利率 > 行业均值 + 20
3. 近 3 年毛利率趋势斜率 > 0
4. 排除上一年年报净利润为负
5. 排除 ST / 退市
6. 排除质押比例 > 50% 或商誉/净资产 > 30%
7. 60 日平均成交额 > 5000 万
8. 60 日平均振幅 >= 1%
9. 市值范围 20 亿到 500 亿
10. PE_TTM < 自身历史 80% 分位

说明：
1. 已移除研发费用占比过滤。
2. 已移除 PEG 过滤。

### 3.3 股票池时间粒度
采用周度股票池：
1. 在回测区间内按周构建基础候选池。
2. 每周候选池仅用于该周新增买入门控。
3. 出池标的不强制清仓，已有仓位继续由信号和风控驱动退出。

## 4. 信号层设计

### 4.1 买入信号（共振）
买入必须同时满足：
1. 布林买入：昨日收盘 <= 昨日下轨，且今日收盘 > 今日下轨。
2. ADX 确认：
   - ADX >= 阈值（默认 20）
   - +DI > -DI

仅当两者同一 bar 同时成立，才生成可买入候选。

### 4.2 常规卖出信号
1. 布林卖出：昨日收盘 >= 昨日上轨，且今日收盘 < 今日上轨。

### 4.3 信号强度
同业超限时使用强度排序：

strength = boll_deviation * adx_value

其中：
1. boll_deviation 为价格相对布林下轨偏离程度。
2. adx_value 为当前 ADX 数值。

## 5. 组合与仓位层设计

### 5.1 资金和仓位
1. 初始资金：1,000,000
2. 总仓位槽位：10
3. 单票目标仓位：10%

### 5.2 约束规则
1. 总持仓数不超过 10。
2. 单行业持仓不超过 3。
3. 若同一行业候选超过上限：
   - 若新信号强度不高于行业内最弱持仓，则跳过。
   - 若新信号更强，则替换行业内最弱持仓。
4. 候选不足 10 只时，剩余仓位保持现金，不补位。

---

## 6. 风控层设计
风控优先级高于常规卖出。

### 6.1 强制止损
当单票浮亏 <= -7% 时立即平仓。

### 6.2 动态止盈
1. 持仓浮盈达到 +10% 后启用。
2. 记录持仓期间峰值收益。
3. 当当前收益相对峰值回撤达到 30% 时止盈平仓。

5. fill_policy：open + bar_offset=1
6. 时区：Asia/Shanghai

## 8. 运行流程

### 8.1 主流程
1. 构建周度基本面股票池。
2. 汇总全周期可交易 symbols。
3. 批量拉取行情数据。
4. 执行策略回测。
5. 输出指标与 HTML 报告。

### 8.2 长耗时阶段说明
在周度股票池构建阶段增加了进度与心跳输出：
1. 预加载阶段输出。
2. 每周选股开始/完成输出。
3. 每 30 秒输出一次仍在运行的心跳日志。

这用于区分慢任务与卡死任务。

3. 动态止盈触发。

---

## 10. 已知注意事项
1. 首次冷缓存运行可能较慢，尤其在周度选股批量调用数据接口时。
2. 周度股票池是买入门控，不是强制调仓清单。
3. 信号强度用于同业超限决策，不直接决定持仓权重。
4. 风控触发后立即平仓，不等待常规卖出信号。
